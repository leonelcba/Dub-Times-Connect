# Dub Times Connect Android — prototipo 0.1

Primera versión Android pensada para probar rápidamente el flujo móvil de Dub Times Connect.

## Compilar sin instalar Android Studio
1. Crea un repositorio en GitHub.
2. Sube **el contenido de esta carpeta** a la raíz del repositorio.
3. Abre la pestaña **Actions**.
4. Entra a **Compilar APK** y pulsa **Run workflow**.
5. Cuando termine, abre la ejecución y descarga el artefacto **Dub-Times-Connect-Android**.
6. Dentro del ZIP está `app-debug.apk`.

El APK debug queda firmado automáticamente para pruebas.

## Alcance de esta primera versión
- Interfaz Android nativa.
- Proyectos y estudiantes.
- Selector de proyecto.
- Vista de personaje/estado.
- Clases y entregas.
- Sesión / “Ver qué pueden grabar”.
- Vista previa del formato nuevo de Discord.
- Datos demo locales para validar el diseño.

La sincronización real con Discord y la base de datos de escritorio todavía no se conectan en este prototipo.
